Offline visual explainer

How Buy or Wait data becomes one purchase recommendation

Two separated views map every participant CSV to its join keys, then show where proposed AI fact extraction ends and deterministic financial calculation begins. The public request_19 trace is explicitly an organizer-provided expected example—not a newly computed prediction.

Read the boundary first. sample_requests.csv supplies public expected answers for development. It is not a label source for evaluation rows in requests.csv. This explainer does not implement a ledger, reproduce a 90-day balance path, or generate output.csv.

Join rules in plain English

user_id
Request → one profile; request/user → that user's events and optional evidence.
request_id
Request → seller offers; optionally scopes messages/images; generated output keeps one row per evaluation request.
related_event_id
Optional evidence pointer to financial_events.event_id. A message may have neither, either, or both optional request/event links.
linked_event_id
Event lifecycle self-link. It provides context; it does not itself make cash spendable or prove a duplicate.
Dated FX key
settlement_date + event currency + home_currency → rate_date + from_currency + to_currency.
image_id
Resolves to dataset/media/images/<image_id>.png. A linked blank event amount must be extracted, never defaulted to zero.

Responsibility split

Proposed AI extraction

Read only relevant untrusted messages/images and return typed, provenance-bearing facts: amount, currency, date, cash state, amendment, cancellation, or settlement. It cannot change challenge rules or authorize spending.

Deterministic financial core

Resolve conflicts/lifecycles and dated FX; build the conservative request-anchored 90-day ledger; calculate no-change capacity; generate allowed schedules; replay every candidate; enforce the minimum, permissions, deadline and exact ranking.

Core safeguards: reserve each pending debit once; ignore unsettled credits and unrealized value; do not replay settled history against the current balance; replace a matching recurrence forecast with its confirmed occurrence.
